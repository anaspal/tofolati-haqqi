# 🦋 طفولتي حقي

### لكل طفل حلم، ولكل حلم حق، ولكل صوت حكاية تستحق أن تُسمع

موقع تفاعلي بمناسبة **اليوم العالمي للطفل**، يمنح الطلبة مساحة ليعبّروا عن أحلامهم وحقوقهم وأصواتهم.

**[🌐 زيارة الموقع](https://anaspal.github.io/tofolati-haqqi/)**

---

## 📖 نبذة عن المشروع

«طفولتي حقي» موقع من إعداد **البرلمان الطلابي** في المدارس الافتراضية غزة الثانوية للعام الدراسي ٢٠٢٦–٢٠٢٧. يعرّف الموقع بحقوق الطفل، ويفتح للطلبة باب المشاركة بأمنياتهم وأفكارهم، ويعرض أحلامهم وإبداعاتهم ورسائل التضامن والأمل إلى أطفال العالم.

## ✨ أقسام الموقع

| القسم | الوصف |
|---|---|
| **الرئيسية** | عدّاد تنازلي ليوم الطفل العالمي، وتعريف بفكرة الموقع |
| **حقوقي** | ست بطاقات تشرح حقوق الطفل، ولكل بطاقة نافذة توضّح معناها وأهميتها |
| **جدار الأمنيات** | مساحة يكتب فيها الطلبة أمنياتهم والحقوق التي يطالبون بها ورسائلهم، مع تصفية حسب النوع وإمكانية الإبلاغ عن أي مشاركة غير مناسبة |
| **صوتي** | أسئلة تتيح للطالب أن يقول رأيه ويُسمِع صوته |
| **أحلامي** | بطاقات مصوّرة لأحلام الطلبة، «طفل اليوم وصانع المستقبل» |
| **رسائل من القلب** | رسائل تضامن وأمل إلى أطفال العالم |
| **اختبر معلوماتك** | مسابقة من ست أسئلة عن حقوق الطفل مع شرح لكل إجابة |
| **المعرض** | إبداعات الطلاب، مع إمكانية تكبير أي عمل |

## 🛠️ لوحة المشرف

للمشرف لوحة مخصّصة، يدخلها بحساب خاص، تتيح له:

- إدارة مشاركات جدار الأمنيات (النشر وإلغاء النشر والحذف)
- مراجعة بلاغات الطلبة عن المشاركات
- الاطلاع على أصوات الطلبة
- إضافة رسائل «رسائل من القلب» وحذفها
- إضافة صور إلى «معرض الإبداعات» و«أحلام الطلبة» وحذفها

## 💻 التقنيات المستخدمة

- **HTML5 و CSS3 و JavaScript** بدون أي إطار عمل
- **Firebase** (Realtime Database والمصادقة) لحفظ المشاركات والمحتوى
- تصميم **عربي من اليمين إلى اليسار** متجاوب مع الحاسوب والجوال
- رسومات **SVG** وحركات تفاعلية (فراشات، بالونات، كونفيتي)

## 📁 هيكل المشروع

```
├── index.html          الصفحة الرئيسية للموقع
├── admin.html          لوحة المشرف
├── banner.png          شعار الموقع
├── firebase-rules.json قواعد قاعدة البيانات
└── content/            صور المعرض وأحلام الطلبة مع ملف بياناتها
```

- **الجهة:** البرلمان الطلابي، المدارس الافتراضية غزة الثانوية ٢٠٢٦–٢٠٢٧
